# Tamagotchi-Pet-Simulator
# 🐾 Python OOP Tamagotchi Simulator

A terminal-based Tamagotchi (Pet Simulator) built in Python to practice Core Object-Oriented Programming (OOP) concepts.

## 💡 Key OOP Concepts Applied
- **Classes & Objects:** Fundamental `Pet` base class and object instantiations.
- **Inheritance:** Derived `Cat` class inheriting features from `Pet` and adding unique behaviors.
- **Encapsulation:** Hidden state management methods (`__zaman_akisi`) to maintain game logic integrity.
- **Properties (`@property`):** Dynamic status attributes and reactive ASCII Art indicators.

## 🛠️ Features
- Real-time hunger, energy, happiness, and health management.
- Dynamic ASCII Art changing based on the pet's current state.
- Terminal UI with automatic screen refresh (`os.system`).

## 🚀 How to Run
```bash
python Tamagotchi-Pet-Simulator.py
